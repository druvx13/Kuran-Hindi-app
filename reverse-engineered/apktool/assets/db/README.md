# assets/db — Binary Excluded

**`Quran.db`** (SQLite, 10.2 MB) is excluded from version control because it is a large binary file
already embedded in the original XAPK at the root of this repository.

To obtain this file, extract the XAPK (it is a ZIP archive) and look inside
`com.muslim.quran_hindi.apk → assets/db/Quran.db`.
